Fix: openfeed held Home Assistant start-up for 5 minutes, then failed to load.

- **No more start-up stall.** In v0.1.13 the usage history count waited for the recorder inside setup. During start-up the recorder doesn't write until start-up has finished, so each waited for the other. After 5 minutes Home Assistant's start-up timeout cancelled the setup and left openfeed in `setup_error`. The count now reads the stored days without waiting, adds the days just imported, and runs in the background ([#41](https://github.com/purcell-lab/ha-openfeed/pull/41), [#40](https://github.com/purcell-lab/ha-openfeed/issues/40)).

If v0.1.13 left openfeed not loaded after a restart, this update fixes it. Update needs a Home Assistant restart.
