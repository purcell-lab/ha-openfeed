Two years of meter history, and the Energy dashboard.

- **Energy dashboard.** Setup now ends with an Energy dashboard step, and the same choice is in **Configure**: leave it as it is, add the meter as a grid connection, or replace the existing grid connections. It's applied once and then reset, so your own changes are never undone. The README has a new Energy dashboard section with the requirements and every option ([#38](https://github.com/purcell-lab/ha-openfeed/pull/38)).
- **Two-year charts.** The sidebar dashboard adds monthly grid import and export and weekly mean and 5-minute peak power, each over 730 days ([#37](https://github.com/purcell-lab/ha-openfeed/pull/37)).
- **Usage history counts the statistics.** `sensor.<meter>_usage_history` now counts the AEST days held in long-term statistics, so it no longer stops at 400 ([#35](https://github.com/purcell-lab/ha-openfeed/pull/35), [#33](https://github.com/purcell-lab/ha-openfeed/issues/33)).
- **Two-year backfill, fewer requests.** The default and maximum backfill is now 730 days. openfeed ignores the start date of a usage request, so a window already returned is skipped (`skipped: covered` in diagnostics) and a partly returned one is trimmed. Everything returned is still imported ([#36](https://github.com/purcell-lab/ha-openfeed/pull/36), [#34](https://github.com/purcell-lab/ha-openfeed/issues/34)).
- **AEST day boundaries documented** in the README ([#26](https://github.com/purcell-lab/ha-openfeed/pull/26)).

Existing entries keep any backfill option already set. Entries with no option now ask for 730 days at each start. Update needs a Home Assistant restart.
