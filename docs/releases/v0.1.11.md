Usage request tracing for openfeed support.

- **Request IDs.** Every openfeed API call now sends a fresh `x-fapi-interaction-id`, and request IDs echoed back by the server are kept ([#30](https://github.com/purcell-lab/ha-openfeed/pull/30)).
- **Usage request trace.** Diagnostics now list the last 6 usage runs per meter under `meters[].usage_requests`. Each run shows the range requested, records per window with first and last date, and each page's status, interaction ID and item count. Account and meter IDs are replaced by `{id}`.
- **Why.** This lets openfeed support match our calls to their logs while they investigate short usage history ([#31](https://github.com/purcell-lab/ha-openfeed/issues/31)).

No new entities or options. Update needs a Home Assistant restart.
