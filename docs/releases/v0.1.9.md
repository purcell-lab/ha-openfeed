Simpler setup.

- **Hosted public key.** Home Assistant now serves the app's public key at `/api/openfeed/jwks.json`. In openfeed, choose **Hosted JWKS URL** and enter that address, instead of pasting a JSON key set. openfeed fetches the key on each sign-in, so re-adding the integration needs no change in openfeed. Only the public half of the app key is published; the private keys and the DPoP key never leave Home Assistant ([#27](https://github.com/purcell-lab/ha-openfeed/pull/27)).
- **One ID.** Setup asks only for the App ID. The `app-` client ID is derived from it. The field also accepts the client ID or the app's page URL.
- **Fallback.** Without an internet-reachable Home Assistant URL, the setup screen still shows the JWKS to paste inline.

Existing entries keep working unchanged. To move an existing app to the hosted key, set its key in openfeed to **Hosted JWKS URL** with `<Home Assistant URL>/api/openfeed/jwks.json` after updating.

Update needs a Home Assistant restart.
